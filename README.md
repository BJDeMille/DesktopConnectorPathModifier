# DesktopConnectorPathModifier
For use with Autodesk ACC/Forma Desktop Connector. This background program automatically updates file paths when copied from within the Desktop Connector folder structure to the more shareable "%userprofile%" format.

To install, download and run the installer found here:
[Desktop Connector Path Modifier](https://github.com/BJDeMille/DesktopConnectorPathModifier/releases/tag/v1.0.0)

To uninstall, use Windows default methods such as the Control Panel or Installed Apps under App Settings.
